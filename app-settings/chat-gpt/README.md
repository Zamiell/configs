# ChatGPT completion sound

## Install

1. Install the ChatGPT desktop app and open it once.
2. Install FFmpeg so `ffplay.exe` is available on the Windows PATH.
3. Put the mp3 file in your Windows user profile directory.
4. Run `./copy.sh` from this directory in WSL.
5. Fully quit and reopen the ChatGPT desktop app, then send a test prompt in a Codex task.

See the [hook documentation](https://learn.chatgpt.com/docs/hooks).
